# Documentation

Project documentation, updated after every completed task.

## Files

- [patterns.md](patterns.md) - reusable code, design, testing and security patterns used in this project
- [changelog.md](changelog.md) - log of completed tasks, newest first
- [ai-verification.md](ai-verification.md) - how the AI pre-review findings were produced and verified

## Conventions

- Add a new topic file (e.g. `architecture.md`, `api.md`, `testing.md`) when a subject outgrows a short section, and link it here.
- Keep entries short and factual. Prefer examples and file references (`path/to/file.ts:42`) over long prose.
