# QA Reviewer: call-summary review

A review surface that helps a QA reviewer decide whether a collections call summary accurately represents its transcript, and whether it needs correcting.

> Work in progress. Sections marked TODO are completed before submission.

## Run locally

```bash
npm ci
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

Requires Node 20+. No environment variables, no database, no API keys.

## Repository layout

| Path | Purpose |
|---|---|
| `data summary/` | Original exercise inputs, unmodified |
| `src/data/calls.json` | Copy of `candidate-calls.json` used by the app |
| `src/data/ai-findings.json` | AI pre-review findings (merged from `ai-review/`) |
| `ai-review/` | Raw AI pre-review output, kept for provenance |
| `docs/` | Changelog, patterns and the AI verification log |
| `AGENTS.md` | Generated by Next.js 16 for AI coding agents; re-created by `next dev` |

## Material assumptions

- The supplied transcript is the only source of truth; no external records.
- Single reviewer, no login. Review decisions are stored in the browser (localStorage) and exported as CSV/JSON.
- AI findings are advisory. They were generated once during the session, not live, and every finding must be accepted or rejected by a human.
- UI language is British English (UK client).
